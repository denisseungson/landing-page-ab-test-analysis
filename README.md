# Análisis de Experimento A/B – Landing Page

## Descripción del proyecto

Proyecto de análisis de datos enfocado en evaluar los resultados de un experimento A/B realizado sobre dos versiones de una landing page.

El análisis busca comparar el comportamiento de los usuarios entre los grupos A y B mediante métricas de conversión y gasto, utilizando análisis exploratorio y pruebas estadísticas para determinar si las diferencias observadas cuentan con evidencia estadística suficiente.

El proyecto también analiza la relación entre variables como la fuente de tráfico, el tipo de usuario y la conversión.

## Objetivos del análisis

El análisis busca responder preguntas relacionadas con:

- La calidad y consistencia de los datos del experimento.
- Las diferencias en el gasto promedio entre las versiones A y B.
- Las diferencias en la tasa de conversión entre ambos grupos.
- La relación entre la fuente de tráfico y la conversión.
- La relación entre el tipo de usuario y la conversión.
- La significancia estadística de las diferencias observadas.

## Mi contribución

Desarrollé el proceso de análisis del experimento utilizando Python, desde la exploración y validación de los datos hasta la aplicación e interpretación de pruebas estadísticas.

Entre las principales actividades realizadas se encuentran:

- Exploración y validación de los datos.
- Comparación del gasto promedio entre los grupos A y B.
- Cálculo y comparación de las tasas de conversión.
- Aplicación de pruebas estadísticas para evaluar las diferencias entre los grupos.
- Análisis de la relación entre variables categóricas y conversión.
- Creación de visualizaciones para apoyar la interpretación de los resultados.
- Interpretación de resultados considerando la significancia estadística y evitando atribuir causalidad sin evidencia suficiente.

## Enfoque estadístico

Las diferencias observadas entre los grupos fueron evaluadas mediante pruebas estadísticas, considerando un nivel de significancia para determinar si existía evidencia suficiente para rechazar la hipótesis nula.

La interpretación distingue entre una diferencia observada en los datos y una diferencia estadísticamente significativa, evitando recomendar cambios únicamente a partir de variaciones descriptivas.

## Resultado y aprendizaje

El proyecto permitió integrar análisis exploratorio de datos y estadística inferencial dentro de un problema de negocio.

Uno de los principales aprendizajes fue la importancia de evaluar las diferencias observadas mediante evidencia estadística antes de formular recomendaciones sobre la implementación de una variante.

También permitió fortalecer habilidades en interpretación de pruebas estadísticas, análisis de conversión y comunicación de resultados sin atribuir causalidad cuando la evidencia disponible no permite establecerla.
